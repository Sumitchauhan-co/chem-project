# 🧪 Interactive Periodic Table

An advanced, responsive, and SEO-optimized digital periodic table built for modern chemistry education. This project leverages Next.js 15 to provide a lightning-fast, interactive experience for exploring chemical elements.

## 🚀 Live Demo

http://chem-project-five.vercel.app

## ✨ Features

- Interactive Grid: High-performance 18-column grid with smooth transitions and hover effects.

- Deep Property Analysis: Detailed data on atomic mass, electron configurations, and chemical phases.

- Tailwind v4 Theming: Seamless Dark/Light mode switching using the latest CSS-variable driven logic.

- SEO Optimized: \* JSON-LD Schema: Implemented as a SoftwareApplication for rich search snippets.

- OpenGraph: Professional preview cards for LinkedIn and Twitter.

- Performance: Optimized with Next.js App Router and semantic HTML.

## 🛠️ Tech Stack

- Framework: Next.js 15 (App Router)

- Styling: Tailwind CSS v4

- Deployment: Vercel

## 📦 Installation

### 1. Clone the repository:

```Bash
git clone https://github.com/Sumitchauhan-co/chem-project.git
cd chem-project
```

### 2. Install dependencies:

```Bash
npm install
```

### 3. Run development server:

```Bash
npm run dev
```

## 📂 Project Structure

- app/layout.tsx: SEO metadata, Viewport, and ThemeProvider.

- app/page.tsx: Periodic Table logic and grid rendering.

- app/globals.css: Tailwind v4 configuration and @theme variables.

- lib/elements.json: Centralized dataset for chemical elements.
